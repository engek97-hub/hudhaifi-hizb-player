# Hudhaifi Hizb Player

Quran memorization by hizb with the recitation of Sheikh Ali Al-Hudhaifi (Hafs ʿan ʿĀsim).
Each of the 60 hizbs plays from its exact first ayah to its last, with ayah and section repeat, pauses for reciting back, and speed control.

Audio streams ayah by ayah from everyayah.com. Hizb boundaries follow the Madinah mushaf.
